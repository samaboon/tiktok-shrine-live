ใส่รูป PNG (พื้นหลังโปร่งใส) ในโฟลเดอร์นี้เพื่อแทนภาพที่โปรแกรมวาดเอง
(โฟลเดอร์ assets/sprites ต้องอยู่ข้างไฟล์ config.toml)

  buddha.png      = องค์พระ (แนะนำ ~600x700 px, ฐานองค์พระอยู่ขอบล่างของรูป)
  character.png   = ตัวละครผู้ชม หันหน้าไปทางขวา (แนะนำ ~300x600 px, เท้าอยู่ขอบล่าง)
  background.png  = ภาพฉากหลัง ใช้เมื่อ background = "scene" (แนะนำ 1080x960)

ไม่มีไฟล์ = ใช้ภาพที่วาดด้วยโค้ด  /  แก้แล้วปิด-เปิดโปรแกรมใหม่
